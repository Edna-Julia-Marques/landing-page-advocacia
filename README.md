## Regras de geração

* Utilize Markdown seguindo boas práticas.
* Organize o conteúdo utilizando títulos (`#`, `##` e `###`).
* Utilize tabelas quando forem úteis.
* Utilize listas para melhorar a leitura.
* Quando alguma informação não for fornecida, escreva **"A ser definido pela equipe"** em vez de inventar dados.
* Não crie tecnologias, funcionalidades ou requisitos que não tenham sido informados.
* Escreva em português (Brasil).
* O resultado deve estar pronto para ser salvo como um arquivo `README.md`.

Ao final, apresente apenas o conteúdo completo do README em Markdown, sem explicações adicionais.
